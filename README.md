# Алгоритм правосудия. Второе мнение

**Интеллектуальная система поддержки анализа судебных решений с использованием искусственного интеллекта.**

Проект разрабатывается в рамках Всероссийского конкурса студенческих проектов «Алгоритм правосудия. Второе мнение», организованного Верховным Судом Российской Федерации.

## О проекте

«Алгоритм правосудия. Второе мнение» — веб-приложение, предназначенное для автоматизированной проверки проектов судебных актов по уголовным делам.

Система использует технологии искусственного интеллекта для извлечения юридически значимой информации, проверки назначенного наказания на соответствие законодательству Российской Федерации и сопоставления рассматриваемого дела с судебной практикой.

Основная задача проекта — предоставить судье дополнительный инструмент для выявления потенциальных несоответствий и ситуаций, требующих более подробного анализа.

**Система не принимает судебные решения, не рекомендует конкретное наказание и не заменяет судью.**

## Основные возможности

### Управление пользователями
- Регистрация и авторизация.
- Личный кабинет пользователя.
- Разграничение доступа к судебным делам и документам.

### Управление судебными делами
- Создание и редактирование дел.
- Добавление документов к делу.
- Просмотр истории работы с делами.
- Поиск и фильтрация документов.

### Работа с документами
- Загрузка документов PDF и DOCX.
- Массовая загрузка файлов и ZIP-архивов.
- Хранение и просмотр документов.
- Скачивание и удаление файлов.

### Интеллектуальный анализ
- Автоматическое извлечение сведений из судебных документов.
- Определение квалификации преступления, обстоятельств дела и назначенного наказания.
- Проверка формального соответствия применимым нормам УК РФ.
- Учет редакции законодательства, действовавшей на момент совершения преступления.
- Выявление потенциальных несоответствий и областей, требующих дополнительной проверки.

### Анализ судебной практики
- Поиск аналогичных судебных решений.
- Сопоставление дел по юридически значимым параметрам.
- Формирование статистической справки.
- Отображение ссылок на нормативные источники и судебную практику.

### Формирование заключений
- Представление результатов анализа в структурированном виде.
- Возможность корректировки извлеченных параметров.
- Повторная проверка документов.
- Сохранение истории результатов.
- Экспорт заключений в PDF и DOCX.

## Технологический стек

### Frontend
- **React** — разработка пользовательского интерфейса.
- **TypeScript** — типизированная разработка.
- **Vite** — сборка и запуск frontend-приложения.
- **Tailwind CSS** — стилизация интерфейса.

### Backend
- **C# / ASP.NET Core Web API** — серверная часть приложения.
- **Entity Framework Core** — взаимодействие с базой данных.
- **Microsoft SQL Server** — основная реляционная база данных.
- **ASP.NET Core Identity** — управление учетными записями и аутентификация.

### Искусственный интеллект
- **Python / FastAPI** — отдельный сервис интеллектуальной обработки.
- **LLM** — извлечение и структурирование информации.
- **RAG** — поиск релевантной судебной практики и нормативных источников.
- **PostgreSQL с pgvector или Qdrant** — возможное специализированное хранилище для семантического поиска.

## Архитектура

Проект строится на основе разделения веб-приложения и сервиса искусственного интеллекта.

**React → ASP.NET Core Web API → AI Service**

Серверная часть ASP.NET Core отвечает за пользователей, судебные дела, загрузку документов, хранение данных и управление процессом анализа.

Данные пользователей, метаданные документов и результаты проверок хранятся в Microsoft SQL Server. Оригинальные документы размещаются в отдельном защищенном файловом хранилище.

ИИ-сервис разрабатывается независимо и взаимодействует с серверной частью через REST API.

## Принцип работы

1. Пользователь авторизуется в системе.
2. Создает судебное дело или открывает существующее.
3. Загружает проект судебного акта в формате PDF или DOCX.
4. Запускает интеллектуальный анализ документа.
5. ИИ-сервис извлекает основные сведения и выполняет предусмотренные проверки.
6. Система отображает результаты, потенциальные несоответствия и релевантные источники.
7. Пользователь при необходимости уточняет извлеченные данные и повторяет проверку.
8. Формируется заключение, доступное для просмотра и экспорта.
